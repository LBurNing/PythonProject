# 序列帧优化工具 设计文档

日期:2026-08-13
状态:已批准(用户确认设计)

## 背景

游戏美术工作流中,序列帧图片需要放入 TexturePacker 打包为 2048×2048 图集(帧间距 4px),且图集最多 10 张。现有工具只能估算图集数(Gif2PngUI.py 的网格公式,偏保守),缺少:播放预览序列帧 + 按 TexturePacker 装箱算法精确计算图集数 + 超限时给出缩小/抽帧建议的能力。

## 目标

1. 选择文件夹播放序列帧(大图预览当前帧 + 横向胶片条显示所有帧、当前帧高亮、点击跳帧)
2. 用 MaxRects 装箱模拟 TexturePacker 计算需要几张 2048×2048(帧间距 4 = TexturePacker padding 语义,帧占 `w+4`)
3. 若 >10 张,给出两种建议(只算不导出):
   - 缩小到 X%(尺寸取偶、LANCZOS 保品质;缩到 <50% 提示品质损失建议抽帧)
   - 每 N 帧取 1 帧(显示抽掉 M 帧、剩 K 帧、所需图集数)
4. 打包 exe「序列帧优化」到桌面,界面样式与打包参考 Gif2PngUI.py

## 界面(暗色卡片式,复刻 Gif2PngUI.py 范式)

| 卡片 | 内容 |
|---|---|
| 文件夹 | 选择文件夹按钮 + 路径框 + 信息行(帧数/尺寸/总时长) |
| 播放 | 大图 QLabel 预览 + 播放/暂停 + 帧计数 + 横向胶片条(QListWidget 缩略图,当前帧橙色高亮,点击跳帧) |
| 图集/优化 | 图集数(2048×2048,间隔 4);>10 张时显示缩小建议 + 抽帧建议 |

## 算法

- **MaxRects 装箱**:帧按面积降序,每帧占 `(w+4)×(h+4)`,Best-Short-Side-Fit 启发式,放不下开新箱
- **缩小建议**:从 100% 向下逐档(0.5%)找最小缩放比例,使取偶缩放后装箱 ≤ 10 张;取偶 `round(x/2)*2`(与 Gif2PngUI.even_height 一致)
- **抽帧建议**:N 从 2 递增,求最小 N 使抽帧后装箱 ≤ 10 张
