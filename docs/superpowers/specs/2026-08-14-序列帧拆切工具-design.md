# 序列帧拆切工具 设计文档

日期:2026-08-14
状态:已批准(用户确认设计)

## 背景

游戏美术工作流中,经常需要把一组序列帧统一裁掉多余区域(如边框、水印、背景残留),只保留角色/内容区域,得到一组新的序列帧。现有 SeqFrameTool 只能预览/缩小/计算图集,缺少"按同一裁剪区域拆切全部帧"的能力。已有 SliceImage/Slice.py 是按 JSON 元数据切图集(无 UI),与本工具场景不同。

## 用户需求(原始描述)

1. 选择一个路径(文件夹),里面是序列帧图片
2. 默认播放起来(选完文件夹自动开始播放预览)
3. 有个框可以拖拽上下左右进行拆切(可拖拽调整的裁剪框,决定拆切区域)

## 目标

1. 选择序列帧文件夹后自动循环播放预览(等比缩放自适应窗口,透明区棋盘格)
2. 预览上叠加可拖拽裁剪框:拖四边/四角调整大小,拖框内部整体移动,框不超出图片
3. 点「拆切」把每一帧按裁剪区域 crop 后保存为新文件夹,保留原文件名与 alpha 通道
4. UI 复刻 SeqFrameTool.py 的暗色卡片式风格;打包 exe「序列帧拆切」

## 界面(暗色卡片式,复刻 SeqFrameTool.py 范式)

| 卡片 | 内容 |
|---|---|
| 序列帧文件夹(蓝 #4488ff) | 路径框 + 浏览按钮 + 信息行(帧数、尺寸) |
| 预览(橙 #ff8800) | 播放/暂停 + 帧号 + 大图预览(裁剪框叠加其上) + 「重置裁剪框」按钮;选完文件夹自动播放 |
| 拆切(绿 #00cc66) | 输出目录(默认 `输入文件夹_裁剪`,可改/可浏览) + 裁剪区信息(原图坐标 x,y,w,h) + 「拆切」主按钮 + 进度条 |

## 裁剪框交互

- 初始框 = 整张图
- 命中检测优先级:四角 > 四边 > 内部移动;光标形状随命中区域变化(SizeFDiagCursor/SizeHorCursor 等)
- 拖动时显示坐标实时刷新;框映射回原图坐标时四舍五入到整数像素(显示预览缩放比,保证框不超出图片)
- 最小裁剪尺寸 4×4(原图像素)
- 「重置裁剪框」把框恢复为整张图

## 拆切执行

- 后台 QThread 逐帧 `Image.crop(原图坐标框)` 后保存,保留原文件名(切成后仍是序列帧),保留 alpha 通道;jpg/bmp 输入转 RGB 保存(与缩小导出逻辑一致)
- 输出目录已有图片文件 → 弹窗确认「清空后重新导出」,同意才继续
- 进度条随帧数推进,最后一帧必发进度 + 完成置满(复用缩小导出的修复逻辑)

## 实现
